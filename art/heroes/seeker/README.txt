HOODED SEEKER - Metroidvania Character  (FREE)

Thanks for trying Seeker! This is the free edition: 6 core
animations in the Void palette.

----------------------------------------------------------------
WHAT YOU GET
----------------------------------------------------------------
- Idle, Run, Jump & Fall, Attack 1, Hurt and Death
- Animation_Guide.txt: how to play each one

Like him? The COMPLETE edition has 22 animations (3-hit combo, bow,

The PRO edition adds 23 pixel VFX, 3 spell casts with the magic
built in and the Dream Seeker palette with rainbow slashes.

----------------------------------------------------------------
CHARACTER SIZE
----------------------------------------------------------------
Seeker is about 17 x 24 pixels standing.
- Made for 16 x 16 tiles: he's one and a half tiles tall.
- Looks right in a 320x180, 384x216 or 480x270 game, scaled up by a
  whole number (x4, x5, x6...).
- A good hitbox: 10 x 22 pixels, standing on the feet point.

----------------------------------------------------------------
GETTING STARTED
----------------------------------------------------------------
1. Import the sheets with point / nearest filtering and no
   compression, so the pixels stay crisp.
2. Slice each sheet by the frame size and frame count in its file name
   (Run_30x30_10f = 10 frames of 30 x 30).
3. Set each animation's origin to its feet point (Animation_Guide.txt
   lists them) and everything lines up.
