Общие правила для всех промтов:
- Все питомцы, стадии и формы (включая Колосс-форму) ставятся в полоску боя, у каждого свои уникальные анимации (решение Сергея 13.11.2026).
- pixelfx — инструмент; всё пишем **с нуля**, стоковые эффекты — только референс, который улучшаем (решение Сергея 13.11.2026).
- Запуск pixelfx агенту разрешён (`hero-look.md` §21.3). Движок клонируется в рабочую папку сессии, в репозиторий не кладётся.
- Свои эффекты лежат в `art/.../pixelfx/<пространство>/`, проверка `node tools/check.mjs <пространство>` без замечаний.
- В игре только листы PNG + JSON; проигрывание без аллокаций в тике; окно полоски — не выше 50 px над землёй и 10 px под ней.
- Превью Сергею — GIF в рабочей папке сессии, в репозиторий превью с чужими фонами и врагами не кладутся.
