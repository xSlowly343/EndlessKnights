# Классы и большое дерево: варианты

**Итог (22.10.2026, третий раунд):** 9 RPG-классов с общим вводом — 5 урона, 2 поддержки, 2 ослабителя; атрибуты Сила/Ловкость/Интеллект; классы и подклассы — concept.md §2.2 и §2.9, дерево подключено в игру. Варианты ниже — история; из них взяты кольцо из 8 стартов с центром, цель 180 очков и поэтапные вехи (§4).

## 0. Из чего можно строить механики

Ввод даёт только счётчики и время, коды клавиш не хранятся (CLAUDE.md). Ровный ритм наградой быть не может: это подарок автокликерам. Поэтому уникальность классов строится на таких сигналах:

| Сигнал | Что считаем | Где уже есть |
|---|---|---|
| Частота нажатий | нажатия в секунду | Печатник |
| «Слова» | серия нажатий, разделённая паузой ≥ 0.4 с; длина серии | новое |
| Enter | отдельный счётчик | Печатник («Точка») |
| Путь мыши | пиксели | Вихрь |
| Взмах | резкий рывок мыши (высокая скорость за 0.1 с) | Вихрь («Рывок») |
| Круги | смена направления движения по кругу | Вихрь («Ураган») |
| Клики | любая кнопка мыши | Стрелок, Бард |
| Пауза перед кликом | секунды без кликов | Стрелок («Прицел») |
| Колёсико | щелчки прокрутки | только «Колесо фортуны» |
| Бездействие | секунды без ввода | Отшельник |
| Смена ввода | переход клавиатура ↔ мышь | новое |
| Длина сессии | минуты без длинной паузы | Фокус |

## 1. Пул классов

Из этого пула собираются 9 классов. Первые 7 уже есть в концепте, остальные новые. В скобках — откуда идея.

| Класс | Ввод | Механика | Фишка для фоновой игры |
|---|---|---|---|
| **Печатник** | клавиши | каждое нажатие — удар, серии дают комбо, Enter — финишер (Tap Titans 2) | сила в частоте |
| **Вихрь** | путь мыши | пройденные пиксели копят клинки, клинки улетают сами; круги и взмахи усиливают (Vampire Survivors) | для тех, кто весь день водит мышью |
| **Стрелок** | клики | клик — выстрел с высоким критом, пауза перед кликом — прицел (osu!, снайперы) | таблицы, браузер, CAD |
| **Отшельник** | бездействие | пока ничего не делаешь, растёт урон и копятся призывы (Cookie Clicker, idle-игры) | AFK и ночь |
| **Бард** | клики как ноты | каждые 4 ноты — мелодия-аура на 20–30 с для себя и пати (Crypt of the NecroDancer) | звезда кооп-пати |
| **Чумной** | клавиши + мышь | нажатия кладут стаки яда, движение мыши ускоряет их тики (PoE: Occultist) | урон идёт и в паузах |
| **Проклинатель** | мышь + клики | клик ставит проклятие, вид проклятия — по жесту мыши перед кликом (Diablo: Necromancer curses) | снимает защиту босса для клана |
| **Рунописец** ✦ | «слова» | каждая серия нажатий между паузами — руна, её сила = длина слова; 3 руны подряд складываются в заклинание по длинам: короткое-короткое-длинное = молния, длинное-длинное-длинное = метеор (Magicka, Noita) | обычная переписка сама даёт руны |
| **Механик** ✦ | колёсико + Энергия | прокрутка «заводит» турели, турели стреляют сами, пока не кончится завод; Энергия чинит и улучшает турели (TF2 Engineer, Factorio) | читаешь длинную страницу — армия турелей |
| **Друид** ✦ | смена ввода | форма зависит от ввода последних 10 с: клавиши — Медведь (тяжёлые удары), мышь — Волк (быстрые укусы стаей), бездействие — Древо (копит рост, отдаёт его разом) (Diablo 4, WoW) | любой стиль работы даёт свою форму |
| **Некромант** ✦ | убийства | каждое убийство поднимает скелета, армия растёт до лимита и бьёт сама; боссы оставляют элитных мертвецов (Diablo 2, Vampire Survivors) | армия работает без ввода |
| **Шулер** ✦ | любой удар | каждый 10-й удар тянет карту из колоды; узлы дерева добавляют и улучшают карты, пары и стриты дают бонусы (Balatro, Slay the Spire) | весёлый рандом без ручного управления |
| **Алхимик** ✦ | золото | часть золота переплавляется в урон, «Золотой удар» тратит запас ради огромного урона; сильнее в экономике, слабее в чистом уроне (TT2: золотые билды) | для любителей экономики |
| **Монах** ✦ | баланс клавиш и мыши | урон растёт, когда клавиатура и мышь дают поровну; перекос копит «смятение» (Diablo 3: Monk, Ци) | для смешанной работы |
| **Странник** ✦ | любой | старт в центре, как Scion в PoE 1: каждые 5 минут берёт бонус того ввода, которым ты пользовался больше всего, и может идти куда угодно по дереву | универсал |
| **Хрономант** | клики + мышь | отложенный урон: «Рок» копит часть урона по врагу и обрушивает его через 5 с, удары повторяются эхом (PoE: Doom) | — подкласс Проклинателя, можно поднять в класс |

✦ — новые классы, в концепте их пока нет.

## 2. Три раскладки по 9 классов

### Вариант A. «Четыре стихии»: квадрат 4 + 4 + 1 ⭐ рекомендую

Четыре атрибута вместо трёх: **Темп** (клавиши), **Размах** (мышь), **Точность** (клики) и новый **Покой** (паузы и бездействие). Чистые классы стоят в углах, гибриды — на сторонах, Странник — в центре. Это прямой аналог PoE 1, только квадрат вместо треугольника.

```
         Печатник ─── Рунописец ─── Отшельник
         (Темп)     (Темп+Покой)     (Покой)
            │                          │
         Чумной       Странник       Друид
      (Темп+Размах)   (центр)    (Покой+Точность)
            │                          │
          Вихрь ──── Проклинатель ── Стрелок
        (Размах)   (Размах+Точность) (Точность)
```

- **Классы:** Печатник, Вихрь, Стрелок, Отшельник, Чумной, Проклинатель, Рунописец, Друид, Странник.
- **Бард** становится подклассом Стрелка («клики-ноты»), или Друид меняется на Барда.
- **Плюсы:** бездействие становится полноценным атрибутом, у каждого класса свой сектор, симметрия как в PoE, Странник в центре добирается куда угодно.
- **Минусы:** нужно пересчитать гемы: требования атрибутов станут четырёхцветными.

### Вариант B. «Шесть снаружи, три внутри»

Три атрибута, как сейчас. Снаружи кольцо из 6 классов: 3 чистых в вершинах и 3 гибрида между ними. Внутри треугольник из 3 классов на «особом» вводе: бездействие, колёсико, смена ввода. Похоже на PoE 2, где старты стоят ближе к центру.

```
                    Печатник
                    (Темп)
          Бард                  Чумной
       (Темп+Точн.)  Отшельник (Темп+Размах)
                  Механик  Монах
          Стрелок                Вихрь
         (Точность) Проклинатель (Размах)
                  (Размах+Точн.)
```

- **Классы:** все 7 из концепта, а также Механик и Монах.
- **Плюсы:** ничего готового не ломается, Бард остаётся классом, колёсико получает своего хозяина.
- **Минусы:** у трёх внутренних классов сектора тесные, им придётся делить центр.

### Вариант C. «Смелый»: кольцо 8 + центр, новые архетипы

Атрибуты те же три, но классы подбираются по разнообразию ощущений, а не по атрибутам. Старты — кольцо из 8 и центр, как часы.

```
                 Печатник
        Шулер               Рунописец
   Некромант     Странник      Бард
        Друид               Вихрь
                 Стрелок
```

- **Классы:** Печатник, Рунописец, Бард, Вихрь, Стрелок, Друид, Некромант, Шулер, Странник (в центре).
- **Чумной и Проклинатель** становятся подклассами (Некроманта и Барда). Отшельник становится подклассом Странника или Друида («Древо»).
- **Плюсы:** самый разный ростер, каждый класс ощущается как своя игра.
- **Минусы:** больше всего новой работы, атрибуты хуже ложатся на кольцо из 8.

### Как сравнить

| | A. Четыре стихии | B. Шесть + три | C. Смелый |
|---|---|---|---|
| Похоже на PoE | очень (PoE 1) | да (PoE 2) | средне |
| Ломает готовое | атрибуты гемов | почти ничего | классы концепта |
| Разнообразие | высокое | среднее | самое высокое |
| Объём работы | средний | меньший | большой |

## 3. Большое дерево

### Размер

В PoE 1 около 1300 узлов при 123 очках: игрок берёт ~10% дерева, остальное — выбор. Предлагаю так же:

| | MVP сейчас | Ранний доступ | Релиз |
|---|---|---|---|
| Узлов | 72 | ~600 | ~1200 |
| Notable | 8 | ~90 | ~180 |
| Keystone | 2 | 20 | 36 (по 2 на класс + 18 общих) |
| Типов мастерства | 2 | 20 | 40 |
| Гнёзд самоцветов | 2 | 12 | 24 |
| Очков к концу | 40 | ~100 | ~160 |

### Устройство (как в PoE)

- **Сектор класса.** Вокруг каждого старта — кольцевая дорога и 6–8 кластеров его механики: notable, малые узлы, мастерство. Сектор даёт статы класса в первую очередь.
- **Большое внутреннее кольцо.** Дорога, соединяющая все сектора. По нему переходят в чужую механику для гибрида.
- **Мосты между соседями.** На границе двух классов — кластеры «смешанных» эффектов: например, между Печатником и Вихрем — «удары клавиш оставляют клинок».
- **Внешнее кольцо.** Keystones и дорогие кластеры на краю. До них долго идти, они меняют правила.
- **Центр.** Колесо Странника и самые общие эффекты: золото, офлайн, опыт.
- **Гнёзда самоцветов** — на развилках, где самоцвет усиливает соседние узлы (как в PoE: «радиус» самоцвета).
- **Атрибутные узлы с выбором** (PoE 2) на дорогах между кластерами.

### Семейства эффектов по секторам

Общие семейства описаны в `tree-effects.md` §2. Сверху у каждого класса свои статы (имена условные):

| Класс | Свои статы в секторе | Keystones сектора |
|---|---|---|
| Печатник | комбо: длина, сила удара серии; Enter; Фокус | Однорукий; Бешеный ритм (Фокус не падает, таймер короче) |
| Вихрь | клинков за 1000 px, скорость полёта, круги ×, взмах | Ураган без конца (клинки не исчезают, но их максимум 5); Пустая рука (клики не бьют, мышь ×2) |
| Стрелок | крит клика, прицел за паузу, пробивание | Снайпер (не чаще клика в 2 с, всегда крит ×4); Пулемёт (крита нет, клики ×1.5 урона) |
| Отшельник / Покой | урон бездействия, раньше начало, призывы, офлайн | Обет молчания; Глубокий сон (офлайн ×2, онлайн-урон −30%) |
| Бард | нот на мелодию, аур одновременно, эффект на пати | Только музыка; Одна песня |
| Чумной | стаки, длительность, тик от мыши, переход стаков | Эпидемия; Тысяча порезов |
| Проклинатель | проклятий на враге, сила, длительность, жесты | Знак мастера (одно проклятие, ×3); Вечные проклятия |
| Рунописец ✦ | рун за слово, длина слова для заклинания, сила заклинаний по длинам | Одно слово (всё заклинание из одной руны, ×2); Красноречие (длинные слова ×2, короткие не считаются) |
| Механик ✦ | турелей, завод за щелчок, сила турелей, ремонт Энергией | Одна большая пушка (1 турель ×5); Самозавод (турели заводятся от времени, колёсико не нужно, сила −40%) |
| Друид ✦ | длина формы, бонусы Медведя / Волка / Древа | Вечный зверь (форма не меняется, её бонус ×1.5); Цикл (каждая смена формы — удар ×5) |
| Некромант ✦ | лимит армии, сила скелетов, элитные мертвецы | Один голем (лимит 1, сила за каждого «лишнего»); Кладбище (скелеты живут 10 с, лимит ×3) |
| Шулер ✦ | размер колоды, тянуть чаще, комбинации | Всё на кон (только старшие карты, но каждая 3-я — пусто); Крапленая колода (карты известны заранее) |
| Алхимик ✦ | доля золота в урон, «Золотой удар», цена улучшений | Мидас (весь урон от золота, прямой ввод ×0.5); Скряга (золото не тратится на урон, золото ×2) |
| Монах ✦ | окно баланса, сила Ци, «смятение» | Путь середины (бонус только при балансе 50/50, ×2); Одна стойка (баланс не нужен, Ци −50%) |
| Странник ✦ | бонус «ввода недели», доступ к любому старту | Подражатель (берёт бонус двух вводов сразу, оба −30%) |

## 4. За что даются очки дерева (решено: 180, поэтапно)

Каждая веха даёт по одному очку на каждой ступени, а не всё сразу. Ступени лежат в `tree_points.json`, уровни и стражи — в `combat.json` (`hero`).

| Источник | Ступени | Очков | В коде |
|---|---|---|---|
| Уровень героя 1 → 100 | каждый уровень | 99 | да |
| Первый страж каждого биома (каждые 50 этапов, до 1000) | каждый страж | 20 | да |
| Нажатия | 10 тыс., 100 тыс., 500 тыс., 1 млн, 5 млн, 10 млн | 6 | да |
| Клики | 5 тыс., 50 тыс., 250 тыс., 1 млн, 5 млн | 5 | да |
| Путь мыши | 1, 10, 50, 100, 500 км | 5 | да |
| Престижи | 1-й, 3-й, 5-й, 10-й, 25-й, 50-й, 100-й | 7 | да |
| Рекордный этап | 250, 500, 750, 1000 | 4 | да |
| Испытания (особые боссы с условием) | каждое испытание | 14 | 14а.13 |
| Бездействие | 10, 100, 500, 1000 ч | 4 | нужен счётчик |
| Мирные активности | каждые 20% музея | 5 | фаза 17 |
| Кооп-помощь | призрак помог убить 1 / 10 / 100 боссов, 10 / 100 ч аур на пати | 5 | фаза 13 |
| Летопись испытаний | рубежи | 6 | 14а.13 |
| **Итого** | | **180** | сейчас 146 |

Очки подкласса (8 за активности) — отдельно.
