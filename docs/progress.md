### Как работать
- Тесты ядра без Unity: `powershell -ExecutionPolicy Bypass -File Tools/test-core.ps1`.
- Тесты Unity и сборка exe: `powershell -ExecutionPolicy Bypass -File build.ps1 -Tests` → `Builds/Windows/RiftWarden.exe`, логи в `Builds/Logs`. Пока проект открыт в редакторе Unity, батч-режим не запустится.
- В редакторе: меню **Game** → «Apply Project Settings», «Build Windows».
- CI запускается на каждый PR и пуш в `main`: `.github/workflows/ci.yml`.
- Оценка в цифрах: ядро — 62 теста, всего в Unity — 66 (EditMode). Сборка IL2CPP: первая около 3 минут, повторные 15–40 с.

### Подводные камни, на которые наступили
- **Цепочка PR.** PR, построенные друг на друге, при слиянии подряд закрываются, когда удаляется их базовая ветка. Делать PR сразу в `main` по одному, а если нужна цепочка — сливать снизу вверх и ждать, пока GitHub перенацелит следующий PR.
- **IL2CPP и Visual Studio.** Без набора C++ и Windows SDK сборка падает с `ToolchainNotFoundException`.
- **Прозрачность окна** работает только на D3D11 без flip model, на D3D12 фон чёрный.
- **Колбэки WinAPI под IL2CPP** — только статические методы с `[MonoPInvokeCallback]`.
- **PowerShell** на ПК запрещает скрипты по умолчанию: запускать с `-ExecutionPolicy Bypass` (в CI это уже прописано).
- **Ограничения агента:** защита Claude Code не даёт агенту ставить программы в автозапуск и запускать фоновые службы. Такие шаги делает Сергей.
- У Сергея на экране оверлей мониторинга (GPU/CPU/FPS) — он виден на снимках поверх окна игры, это не баг игры.
