# Дизайн-система интерфейса Rift Warden

Статус: **черновик агента 11.11.2026 на утверждение Сергея.** Опирается на принятое: палитра «Ночной сапфир» и шрифты (`visual-style.md` §6, решения 22.10.2026), одна панель над полоской (`ui-layout.md`, решения 23.10.2026), пиксель-арт в полоске (решения 08.11.2026). Дерево слева направо — решение Сергея 11.11.2026 (§7).

Макеты: [холст «Rift Warden — UI/UX система»](https://claude.ai/artifact/TZJ93a7XQHH4dbuYJAS3rh), 29 артбордов. Исходники лежат в `docs/ui-mockups/kit/`: по файлу `.dc.html` на артборд, общий файл стилей `rw.css` и `canvas.json` с раскладкой холста. Список окон и их спецификации — `ui-screens.md`.

`rw.css` — источник правды для чисел этого документа: цвета заданы переменными в `:root`, размеры — классами компонентов. При расхождении текста и файла верен файл.

## 1. Принципы

1. **Игра фоновая.** Интерфейс занимает столько места, сколько нужно для действия, и не закрывает рабочее окно. Полоска не двигается и не перекрывается никогда.
2. **Одна панель, один уровень вложенности.** Раздел → подвкладка → вложенный экран со стрелкой «назад». Глубже не уходим.
3. **Описание выбранного — нижний лист.** Узел, предмет, гем, постройка: карточка прижата к низу содержимого. Отдельных окон с описанием нет.
4. **Причина на месте.** Недоступная кнопка серая, причина написана под ней или в подсказке. Окно с ошибкой не открывается.
5. **Цвет не единственный признак.** Редкость дублируется словом и формой рамки, состояние — значком или подписью.
6. **Числа — из ядра.** Все тексты и цифры берутся из `Game.Core.Ui` и `strings.json`. В `Game.Presentation` своих строк нет.

## 5. Форма

Интерфейс стоит над пиксельной полоской, поэтому крупные рамки ступенчатые, а мелкие элементы — с малым радиусом и «гранью» снизу.

- **Панель, нижний лист, диалог:** срез угла двумя ступенями по 3 px. Рамка 2 px — градиент сверху вниз `#6176B0 → #2A3454`. Диалог-предупреждение — рамка `#E5484D → #7A1E24`, диалог награды и престижа — `#F0B43C → #8A5C12`. В Unity это один 9-slice спрайт рамки и один спрайт маски угла.
- **Плашка заголовка:** прямоугольник со скошенным правым краем (10 px), золотая нить 2 px снизу.
- **Карточка, строка:** радиус 4, блик 1 px сверху (белый 7%), тень-грань 2 px снизу (чёрный 22%).
- **Кнопка:** радиус 4, блик сверху 20%, грань снизу 3 px (чёрный 30%). Нажатая сдвигается на 2 px вниз, грань пропадает. В коде уже есть `UiSprites.RaisedRounded`.
- **Ячейка:** радиус 4, рамка 2 px цвета редкости; пустая — пунктир. Бижутерия и артефакты — круг.
- **Гемы:** активный скилл — ромб, поддержка — круг, аура — шестигранник (`visual-style.md` §9).
- Градиенты только в рамке панели, плашке и фоне сцены. Размытых теней и стекла нет.

## 6. Компоненты и состояния

Артборд «02 Компоненты и состояния». Классы — из `rw.css`.

| Компонент | Класс | Состояния |
|---|---|---|
| Кнопка | `.bt` + `.g` главная, `.bl` вторичная, `.rd` опасная, `.vi` Эхо, `.o` контурная | обычная; наведение — ярче на 14%; нажата — сдвиг 2 px; фокус — обводка `--res` 2 px с отступом 2; недоступна `.d` — серая, причина рядом |
| Кнопка-значок | `.ib` | обычная; включена `.on` (золото); закрыть `.x` |
| Подвкладка | `.pl` | обычная; активная `.on`; с красной точкой |
| Фильтр | `.pl.sm` | обычный; активный |
| Сегменты | `.sg` | 2–5 взаимоисключающих значений |
| Тумблер | `.tg` | выкл; вкл (зелёный) |
| Галочка | `.cb` | пусто; отмечено (золото) |
| Ползунок | `.sd` | значение числом справа; ноль подписан словом |
| Поле | `.inp` | пусто; фокус; ошибка (красная рамка) |
| Прогресс | `.pg` (8), `.tk` (14), `.th` (4) | цвет заливки по смыслу |
| Деления уровня | `.pip` | 3–5 делений |
| Чип | `.ch` + `.gd`, `.gn`, `.rd`, `.vi`, `.bl` | метка состояния или условия |
| Строка списка | `.li` | обычная; выбранная — золотая рамка 2 px внутрь; закрытая — 50% и замок |
| Карточка | `.cd`, тёмная `.dk`, «разломная» `.rf` | выбранная `.sel`; погашенная `.off` |
| Ячейка | `.sl` + `.q0`…`.q10`, `.uq`, `.rnd`, `.e` | выбранная — золотая обводка снаружи |
| Метки ячейки | `.mk` | новая — красная точка справа сверху; лучше надетой — зелёная стрелка справа снизу; избранное — звезда слева сверху; сетовая — звено слева снизу |
| Нижний лист | `.sh` | золотая линия 2 px сверху; у уникальной вещи — цвет редкости |
| Диалог | `.dg` поверх `.scr` | обычный; предупреждение; награда |
| Подсказка | `.tp` | выходит наружу панели |
| Уведомление | `.ts` | до 3 сразу над полоской |
| Пустое состояние | `.em` | значок 40 px, одна фраза: что это и откуда берётся |

Правила состояний:
- Выбор не меняет размер элемента: рамка рисуется внутрь.
- Закрытое показывается всегда: замок и условие открытия словами («этап 100», «ур. 50», «от вещи»).
- Красная точка означает «есть что забрать или потратить»: свободные очки, новая вещь, приглашение, невзятая награда. Для новостей без действия точки нет.

## 7. Деревья: слева направо

Решение Сергея 11.11.2026: все деревья рисуются одним способом (артборды «32 Дерево класса», «62 Эхо › Атлас», «83 Спутники › Зверинец», «51 Клан»).

- **Ряд = колонка.** Слабые ряды слева, сильные справа. Узлы колонки стоят столбиком.
- **Узел** — квадрат 28 px с номером колонки. Справа название, под ним точки уровня (по одной на уровень). В панели 480 название стоит под узлом в две строки.
- **Цвет квадрата — вид узла:** малый `#5B6FA8`, средний `#2F8F9A`, легендарный `#D9772A`, ключевой (компромисс) `#B8403A`. У других деревьев свой базовый цвет: Атлас `#6B4FB0`, Зверинец `#3E8A5A`.
- **Рамка — состояние:** золотая 2,5 px — взят или доступен, белая 3 px — выбран, без рамки и 36% непрозрачности — закрыт.
- **Связи** — плавные линии от узла к узлу: золотая 2,5 px, если оба конца взяты, иначе `--line` 1,5 px.
- **Карточка узла** появляется у узла по клику (в панели 480 — нижним листом): вид и уровень, название, пороги уровней 1 / 3 / 5, строка «ур. N: было → станет», кнопка «+1 уровень», рядом «−1».
- **Полоса мастерства** под полем: вложено из максимума, деления каждые 10, ромбы больших талантов на порогах. Под ромбом три варианта, выбранный помечен «▶» и белым.
- **Легенда** одной строкой под полосой.
- **Шапка:** плашка «Дерево», вкладки-«таблетки» деревьев с числом очков («Runedancer · 57», «Удача · 12», «+ слот»), разделитель, «Пути», «Скрижали»; справа «Свободно очков», «Докачать по сборке», смена ширины, закрыть.

Что нужно в коде:
- Широкий режим 1200×640 вместо 960×640: семь колонок с названиями в 960 не помещаются (шаг колонки 166 px против нужных 130 px на самое длинное название и узел). Меняются `PanelGeometry.WideWidthPx` и размер окна (`engine-spec.md` §4: окно под самую большую панель).
- Поле рисуется одним мешем (узлы, связи, точки), как требует `visual-style.md` §8; подписи — TMP из пула.
- Кнопка «Докачать по сборке» есть в образце Сергея, модели в ядре для неё нет — см. `ui-screens.md` §6.

## 9. Движение

Все твины — DOTween, без аллокаций в цикле. Длительности короткие: игра не должна отвлекать от работы.

| Что | Как | Время |
|---|---|---|
| Панель открывается | рост из полоски вверх, содержимое проявляется | 0,15 с |
| Смена высоты и ширины | твин размера `RectTransform` | 0,15 с |
| Смена вкладки и подвкладки | содержимое проявляется, без сдвига | 0,1 с |
| Нижний лист | выезжает снизу | 0,12 с |
| Диалог | затемнение содержимого, диалог растёт с 96% | 0,12 с |
| Кнопка | сдвиг 2 px при нажатии | сразу |
| Уведомление | выезжает снизу вверх, держится 3 с, гаснет | 0,2 / 3 / 0,3 с |
| Красная точка | один «вздох» масштаба при появлении | 0,3 с |
| Счётчик валюты | подпрыгивает на 10% при изменении | 0,15 с |
| Узел дерева взят | вспышка рамки, точка уровня заполняется, линия загорается | 0,2 с |
| Прогресс | заливка догоняет значение | 0,25 с |
| Редкость 9–10, уникальные | медленное мерцание рамки | цикл 2–3 с |

- Настройка «от батареи» и скрытая панель останавливают все циклические анимации.
- Статичное и подвижное лежат на разных `Canvas`: каркас панели и списки перестраиваются только по событию, счётчики, прогресс и таймеры — на отдельном холсте.

## 10. Клавиатура

- `Esc` сворачивает панель; в диалоге — «Отмена»; во вложенном экране — «назад».
- `Tab` и `Shift+Tab` обходят элементы слева направо, сверху вниз; у сфокусированного элемента обводка `--res`.
- `Enter` и пробел нажимают сфокусированное. В диалоге фокус по умолчанию стоит на безопасной кнопке («Отмена», «Остаться»).
- Колёсико над нижним рядом листает вкладки, над полем дерева — прокручивает колонки, над полоской в мирном режиме — меняет занятие.
- Глобальных горячих клавиш по умолчанию нет: игра считает ввод в чужих окнах и не должна перехватывать клавиши.
- Клики ЛКМ и ПКМ по панели не должны запускать скиллы: пока курсор над интерфейсом игры, ввод мыши идёт в интерфейс. В коде не проверено — вопрос 6 в `ui-screens.md` §9.
