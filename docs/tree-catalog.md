# Каталог узлов дерева и скрижалей (черновик агента, 30.10.2026)

Источник для задач 14в.4в (деревья 18 классов), 14в.4г (скрижали), 14в.6 (особенности) и 14в.7 (Пути). Устройство дерева — `tree-v3.md`, механики классов — `classes-v2.md` §2, метки и отклики — `classes-v2.md` §1.

**Откуда что взято.** У Torchlight Infinite заимствуются только принципы: узлы с несколькими уровнями, узлы, открытые вложенными очками, большие таланты 1 из 3 на порогах со сменой бесплатно, скрижали — плитки разной формы с готовыми талантами, которые кладут на поле. Названия, тексты и цифры TLI не переносятся: у нас другой ввод (клавиши, мышь, паузы, отряд), поэтому все узлы и скрижали ниже — свои, под наших 18 персонажей. Все цифры — черновик для симулятора.

## 1. Схема дерева класса (50 узлов)
Одинаковая для всех 18 классов, чтобы деревья читались одинаково, а различались содержанием.

## 3. Классовые узлы и большие таланты 18 классов
Формат: ветка — узлы по рядам («имя — мысль»). Связки — по `classes-v2.md` §1.2. Большие таланты — 3 варианта на каждой отметке полосы (20 / 50 / 90 / 140), правило §2.1 `tree-v3.md`: числа и условия, без особенности, ресурса как источника, меток и скиллов.

### 3.1. Huscarl (Гнев, щит предков) — полностью в `trees/viking.json`
- Оружие: Топор, Окованный щит (р1) → Тяжёлый замах → Окованный обод → Топор ярла → Северный ветер.
- Ресурс: Гнев → Кровь кипит, Северная выдержка → Неистовство → Неугасимый → Кровавая жатва → **Неугасимая ярость** (вершина).
- Особенность: Щит предков → Тяжёлый щит → Стена щитов → **Берег предков**.
- Тяжёлый скилл: Без жалости → Последний удар → Сокрушение. Мышь: Разбег → Бег по снегу → Разгон.
- Прочее: Закалка (Сила), Боевой рог (отряд), **Один на один** (босс против волн).
- Связки: Серия · Аура · Кровь · Призыв.
- **Пассивные способности** (20, на местах прежних общих узлов, черновик; в `trees/viking.json` с PR 304, узлы с `"passive": true`): ряд 1 — Закалённый глаз (крит клавиш при Гневе > 50), Боевой транс (Фокус быстрее при Гневе), Добыча хирдмана (золото за оглушённых), Вызов (урон по боссу за каждые 10 Гнева), Клич (урон отряда на полном Гневе); ряд 2 — Охота на великана (удары по боссу дают Гнев), Глаз ворона (каждый N-й удар — крит), Холодное дыхание (Фокус не сбрасывается, пока Гнев > 30), Трофеи (шанс гема с оглушённых); ряд 3 — Песнь саги (серия держит Гнев), Добить лежачего (урон по оглушённым), Сундук ярла (офлайн-золото за Гнев перед выходом), Щит соседа (Оглушение даёт отряду урон); ряд 4 — Ярость на Колосса (таймер босса медленнее на полном Гневе); ряд 5 — Ледяной расчёт (крит. множитель за Гнев), Долгая зимовка (офлайн-урон); ряд 6 — Убийца великанов (урон по боссу и стражам), Терпение северянина (Фокус копится в паузах, пока есть Гнев); ряд 7 — Берсерк в сердце (урон ×1,3, Гнев сгорает вдвое быстрее), Побратим скальда (урон отряда +15%, свой −10%).
- Большие таланты: 20 — Тлеющие угли / Разогрев / Жадный топор; 50 — Топор наготове / Холодная голова / Против великана; 90 — Затяжной бой / Быстрая расправа / Тяжёлая рука; 140 — Ярость без края / Каждый удар на счету / Вождь.

### 3.2. Wandering Blade (Дыхание клинка, серия)
- Оружие: Катана, Тонкий срез → Ровный хват → Второй срез → Меч странника → Рассечённый ветер.
- Ресурс: Дыхание → Длинный выдох, Счёт ударов → Полная грудь → Без вдоха → Ветер в спину → **Последний вдох** (Дыхание до 8, но рвётся с первой паузой).
- Особенность: Серия → Удар насквозь (серия задевает двоих) → Серия серий → **Тысяча шагов** (удар серии каждые 40, но ×2 вместо ×3).
- Тяжёлый: Сто срезов → Срезы по очереди → Последний из ста. Мышь: Танец клинков → Шаг в сторону → Вихрь.
- Прочее: Закалка (Ловкость), Пример для отряда (серия отряда держится дольше), **Один клинок** (урон ×1,4, скиллов на 1 меньше).
- Связки: Метка охотника · Узы · Яд · Призыв.
- Большие таланты: 20 — Медленный счёт / Острый край / Не оглядываться; 50 — Тонкая работа / Широкий замах / Терпение; 90 — Ветер и сталь / Дыхание в запас / Поток; 140 — Путь без конца / Серия на всех / Дуэлянт.

### 3.3. Huntress (Добыча, помеченная цель)
- Оружие: Короткий лук, Стрела с дороги → Тугая тетива → Вторая стрела → Лук следопыта → Стрела насквозь.
- Ресурс: Добыча → Следы, Запас в колчане → Охотничий азарт → Сытая охота → Трофеи → **Последняя стрела** (вся Добыча в один выстрел, копится вдвое медленнее).
- Особенность: Помеченная цель → Метка держится дольше → Меченый вожак (метка переходит на следующего) → **Одна цель** (метка ×2, но только на боссе).
- Тяжёлый: Тропический ливень → Ливень гуще → Шквал стрел. Мышь: Тропа → Глаз следопыта → Широкий обход.
- Прочее: Закалка (Ловкость), Добыча на всех (золото отряду), **Засада** (первый удар по врагу ×3, дальше −15%).
- Связки: Молния · Аура · Холод · Яд.
- Большие таланты: 20 — Неспешный шаг / Быстрый колчан / Свежий след; 50 — Голова зверя / Стая птиц / Тихая охота; 90 — Ловчая сеть / Охота до темноты / Двойной трофей; 140 — Королевская охота / Охотница стаи / Без промаха.

### 3.4. Stormcaller (Гроза, перегрузка)
- Оружие: Жезл бури, Искра с пальцев → Сухой воздух → Дуга → Посох грома → Шаровая молния.
- Ресурс: Гроза → Трение, Наэлектризованный → Тяжёлые тучи → Громоотвод (Гроза не уходит в паузах) → Штормовой фронт → **Ураган** (перегрузка на 150, но ×2).
- Особенность: Перегрузка → Цепь (молния на 3 врагов) → Эхо грома → **Молния в бутылке** (перегрузка не сама, а по клику).
- Тяжёлый: Плащ-туча → Туча дольше → Гроза над головой. Мышь: Трение → Резкий взмах → Вихрь искр.
- Прочее: Закалка (Интеллект), Небо над отрядом (молния по удару союзника), **Буря без берегов** (урон по волнам ×1,5, по боссу ×0,8).
- Связки: Метка охотника · Узы · Холод · Призыв.
- Большие таланты: 20 — Тихая гроза / Частые разряды / Статика; 50 — Сухая молния / Цепь длиннее / Разряд в землю; 90 — Ночная гроза / Синяя вспышка / Электролиз отряда; 140 — Небесный кузнец / Поющий провод / Вечный шторм.

### 3.5. Wayfarer (Мираж, попутчик)
- Оружие: Ятаган, Отцовский ятаган → Лёгкая рука → Песчаный срез → Клинок пустыни → Тень миража.
- Ресурс: Мираж → Понемногу от всего, Вода в фляге → Караван → Привал без остановки → Оазис → **Мираж без края** (ресурс от всего ×2, предел вдвое меньше).
- Особенность: Попутчик → Чужие знаки (+1 к пределу меток) → Песок в глаза (Ослепление чаще) → **Всем по пути** (бонус за метки и отряду).
- Тяжёлый: Попутчик из песка → Двойник дольше → Два двойника. Мышь: Дорога → Петля пути → Длинный переход.
- Прочее: Закалка (Ловкость), Проводник (отряд ресурс +), **Ни в чём не лучший** (+5% ко всему, −10% к своему лучшему).
- Связки: Серия · Узы · Время · Огонь.
- Большие таланты: 20 — Лёгкий шаг / Тяжёлая фляга / Песня дороги; 50 — Чужой огонь / Чужой счёт / Чужое время; 90 — Дальний свет / Ночлег / Перекрёсток; 140 — Вечный путник / Пустыня внутри / Карта мира.

### 3.6. Skald (Овердрайв, слышно всем)
- Оружие: Электрогитара, Песня у камина → Чистый строй → Припев → Гитара-рог → Последний аккорд.
- Ресурс: Овердрайв → Громкость, Хэдбэнг → Перегруз → Без пауз → Зал поёт → **Вечный концерт** (песни отряда не гаснут, своих ударов −20%).
- Особенность: Слышно всем → Громче отряду → На бис (песни ×1,5 дольше) → **Хор над полем** (бонус отряда ×2, только пока в отряде).
- Тяжёлый: Громче! → Молния на струнах → Стена звука. Мышь: Хэдбэнг → Длинное соло → Бас в груди.
- Прочее: Закалка (Сила), Песня для своих, **Голос без гитары** (урон отряда +20%, свой ×0,7).
- Связки: Узы · Холод · Огонь · Ослепление.
- Большие таланты: 20 — Тихий проигрыш / Громкий старт / Тёплый зал; 50 — Медь / Струна / Барабан; 90 — Баллада / Марш / Плясовая; 140 — Легенда сцены / Песня Колосса / Последний тур.

### 3.7. Seer (Видения, ясный день)
- Оружие: Святая сфера, По походке → Свет в ладони → Второе зрение → Сфера пророка → Свет сквозь.
- Ресурс: Видения → Чтение знаков, Тихий взгляд → Долгий сон → Ясная голова → Вещий сон → **Слепая вера** (крит отряда выше, своё зрение — ресурс копится только от чтения).
- Особенность: Ясный день → Добрый знак (+крит отряду дольше) → Предсказанный крит → **Пророчество** (крит отряда +10% от 80 Видений, ниже — ничего).
- Тяжёлый: Добрый прогноз → Прогноз на неделю → Всё сбудется. Мышь: Чтение → Знаки на ладони → Звёздная карта.
- Прочее: Закалка (Интеллект), Глаза отряда, **Не для себя** (крит отряда +, свой урон ×0,7).
- Связки: Узы · Проклятие · Кровь · Призыв.
- Большие таланты: 20 — Медленное чтение / Быстрый взгляд / Сон наяву; 50 — Удача отряда / Своя звезда / Чужие сны; 90 — Знамение / Затмение / Рассвет; 140 — Видящая / Голос неба / Тысяча глаз.

### 3.8. Herald (Доблесть, постоянные ауры)

## 4. Скрижали (вместо самоцветов дерева, `tree-v3.md` §2.2)

> **31.10.2026 (PR 321):** скрижали сделаны в ядре по этому разделу: `slates.json`, `SlateSystem`, подробности и цифры — `dev-notes.md` (Sim, 14в.4г). Классовые строки — для 14 классов в коде (у Spinner, Rimecaller, Thornmaiden, Clayshaper — вместе с 14в.8).

### 4.1. Поле
- Поле рядом с деревом класса. Старт — 4×4 клетки; каждый Предел добавляет ряд или колонку по очереди, до 8×8 (черновик).
- Скрижаль кладут в любое свободное место, поворачивают на 90°, снимают бесплатно; одинаковые скрижали класть можно.
- Поле общее для всех классов героя: при смене класса скрижали остаются на месте; классовая строка скрижали чужого класса молчит.

### 4.2. Формы
| Форма | Клеток | Строк талантов |
|---|---|---|
| Камешек | 1 | 1 |
| Палка | 2 | 1 |
| Уголок | 3 | 2 |
| Брусок | 3 | 2 |
| Квадрат | 4 | 2 |
| Т | 4 | 2 |
| Зигзаг | 4 | 2 |

Чем больше клеток, тем сильнее строки (×1 за 1–2 клетки, ×1,5 за 3, ×2 за 4) — за место на поле платишь силой.

### 4.3. Редкость
Обычная (1 строка, слабая), редкая (строки +25%), эпическая (+1 строка закалки), легендарная (одна строка — правило, как у узла ряда 6). Выпадают с боссов (шанс растёт с этапом), со стражей Пределов (гарантированно редкая и выше), из Разлома (по глубине) и из подземелий.

### 4.4. Темы и таланты скрижалей
У каждой скрижали **тема** (как у узлов: клавиши, мышь, скиллы, крит, Фокус, босс, добыча, отряд, ауры, проклятия, яд и огонь, призыв) и 1–2 строки из пула темы.

- **Общие строки** (по 3–4 на тему, ~40 всего): например, клавиши — «урон клавиш», «каждый N-й удар ×2»; мышь — «урон кликов», «ресурс за путь мыши»; крит — «шанс крита», «крит. множитель»; добыча — «золото», «шанс скрижали»; отряд — «урон отряда», «ресурс отряда».
- **Классовые строки** (по 2 на класс, 36 всего): усиливают особенность или ресурс класса, работают только у него — например, Huscarl «щит каждые 13 ударов», Venomist «пары каждые 9 ударов», Undertaker «+1 скелет к пределу», Spinner «Узы держатся на 2 с дольше».
- **Строка-связка** (редкая и выше): «+X% урона по врагу с меткой <М>» — помогает собрать отклик, которого нет в дереве.

### 4.5. Смежность (улучшение против TLI)
- Скрижали **одной темы**, касающиеся сторонами, усиливают друг друга: +10% к строкам за каждую соседнюю той же темы, до +30%.
- **Узор**: 4 и больше скрижалей одной темы одним куском дают строку узора темы (например, клавиши — «удары клавиш не теряют серию 1 с»). Узоры — по одному на тему.

### 4.6. Закалка и разбор
- **Закалка** (вместо «клейма» TLI): за Осколки скрижаль получает ещё строку темы с шансом 60%; с шансом 40% ничего не меняется. Закалить можно один раз.
- **Разбор** — в Пыль по редкости.

> **30.10.2026 (PR 308):** классы продуманы заново под дерево v3 — полный разбор, 20 пассивных способностей каждого класса и все строки узлов и больших талантов — в `class-trees.md`; файлы `trees/<класс>.json` для всех 18 классов (в игре пока только Huscarl).
