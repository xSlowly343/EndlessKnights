# Классы v3: разбор и деревья 18 классов (черновик агента, 30.10.2026)

По просьбе Сергея (30.10.2026) классы продуманы заново под дерево v3 до наполнения деревьев: у каждого класса — как он играется, 50 узлов (30 классовых в ветках оружия, ресурса, особенности, скиллов, мыши и 4 связки + 20 **пассивных способностей** на местах прежних общих узлов), 12 больших талантов и список механик, которых ждут строки `waits`. Принятые механики (`classes-v2.md` §2: ресурс, мышь, особенность, стартовые скиллы, метки, Пути) не менялись; предложения по ним — в §19. Имена узлов — из `tree-catalog.md` §3, где имя занято в другой ветке, дано новое.

**Как читать.** Раскладка у всех классов одна (как у Huscarl, `tree-v3.md` §4): ряд, место и родитель совпадают. Строка А — уровни 1, 2, 4 (×1, ×2, ×3), Б — уровень 3, В — уровень 5. «(н)» — строка ждёт механику (`waits`), в бою пока ничего не даёт. Числа — черновик для симулятора. Статы проверены генератором агента: только статы с механикой в коде, у статов с базой 0 — только flat, в больших талантах нет статов из `majorTalentsAvoid`.

**Где лежит.** Деревья — `trees/<класс>.json` (версия 5). Huscarl играет на своём с PR 301; остальные 13 классов из кода включаются в `trees/templates.json` → `classes` в задаче 14в.4в после просмотра Сергеем; 4 новых класса (Spinner, Rimecaller, Thornmaiden, Clayshaper) — вместе с самими классами (14в.8), их файлы проверяет тест загрузки.
