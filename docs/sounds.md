# Звуки игры

Решение Сергея 13.11.2026: **все звуки игры делаем сами**, синтезом, без чужих сэмплов и наборов. Основная работа над звуком — в самом конце, когда игра собрана; звуки переходов сделаны раньше как образец и основа генератора.

## 1. Инструменты
- **Python 3 + numpy + scipy** (лицензия BSD): `pip install numpy scipy`. Звук собирается из волн, шума и фильтров, поэтому каждый файл целиком наш и лицензия на результат не нужна.
- Генераторы лежат в `Tools/sfx/`. Один генератор — одна группа звуков; запуск без аргументов перезаписывает файлы группы.
- jsfxr или sfxr (`setup.md` §5) можно брать для быстрых заглушек, но в игру идут только звуки из своих генераторов.
- Audacity — только чтобы послушать и сравнить, правки вносятся параметрами генератора, а не руками в файле.

## 2. Правила для любого звука
- **Формат:** WAV, 44,1 кГц, моно, 16 бит; лежат в `Assets/Game/Art/Resources/Sounds/<группа>/<ключ>.wav` и уходят в Git LFS (`.gitattributes`). Meta-файлы Unity создаёт при импорте на ПК.
- **Ключ файла = ключ в коде.** Нет файла — тишина, игра не падает (так работает `TransitionSounds`).
- **Громкость:** выравнивание по RMS к −18 дБ и мягкое ограничение (`tanh`), пик не выше −1,5 дБ. Нормализация по пику не годится: ударные звуки выходят на 15 дБ тише тянущихся.
- **Повторяемость:** сид случайности берётся из ключа, повторный запуск даёт побайтно те же файлы. Это проверяется сравнением хешей до и после.
- **Длина** берётся из данных игры, а не задаётся в генераторе руками (у переходов — длины фаз из `panel.json`), плюс короткий хвост на затухание.
- **Кирпичики** (`Tools/sfx/transition_sounds.py`, их можно переиспользовать в новых генераторах):
  - металл, колокола, стекло — суммы негармонических обертонов с затуханием;
  - треск огня, разрыв — случайные щелчки через полосовые фильтры;
  - шаги, удары — синус с падающим тоном и шум;
  - рог — «пила» с вибрато через фильтр;
  - гомон — шум в полосе голоса с рваной громкостью;
  - эхо — свёртка с синтетическим откликом.
- **Проверка:** агент слушать не может, поэтому после генерации проверяет числа (длина, пик, RMS, ноль в конце) и присылает Сергею один общий файл со всеми звуками группы подряд; на ПК звук слушают в игре.
