# Первое сообщение агенту (скопировать в чат)

Привет! Мы делаем фоновую кооп-игру для Windows на Unity. Вся документация лежит в папке docs/, а правила работы — в CLAUDE.md в корне репозитория. Прочитай CLAUDE.md, затем docs/roadmap.md, docs/engine-spec.md и docs/setup.md (что должно быть установлено: Unity 6.3 LTS, Visual Studio, Git LFS). Unity MCP подключается по docs/mcp-setup.md.

Порядок работы:
1. Бери задачи из docs/roadmap.md строго по порядку, по одной. Начни с фазы 0 (задачи 0.1–0.6).
2. Каждая задача — отдельная ветка и отдельный PR, с быстрым тестом из колонки «Быстрый тест».
3. После каждой задачи коротко напиши мне: что сделано, как проверить и что мне нужно проверить руками, если тест ручной.
4. На шагах с 🧑, на «воротах» 🚦 и после каждой задачи фазы 14а останавливайся и жди моего решения.
5. Жёсткие правила из CLAUDE.md (полный список в engine-spec.md §0) не нарушай никогда. Главные: **ничего не удаляй без моего явного «да»** и **никаких заметок в коде**, все заметки в docs/dev-notes.md и docs/todo.md.

Если документы противоречат друг другу или чего-то не хватает, спроси меня, а не додумывай.

Для начала: прочитай документы и в 5–10 строках перескажи, как ты понял игру и первые 3 задачи. Код пока не пиши, сначала подтверди понимание.
